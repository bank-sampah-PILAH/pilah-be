🔐 Authentication: Semua endpoint (kecuali POST /auth/google) memerlukan header Authorization: Bearer <access_token>. Token didapat setelah Google OAuth berhasil.

🏢 Multi-tenancy: Semua data yang diakses secara otomatis difilter berdasarkan bank_sampah_id dari JWT. Pengelola hanya bisa mengakses data bank sampah miliknya sendiri.

🔑 Authentication

Login via Google OAuth 2.0 dan manajemen sesi JWT

POST /auth/google Login / Register via Google OAuth

Menerima Google ID Token dari Flutter (setelah user login Google di client), memverifikasinya, dan mengembalikan JWT. Jika akun belum ada, otomatis dibuat dengan role pengelola.

Request Body
FieldTypeRequiredDescription
id_tokenstringRequiredGoogle ID Token dari Google Sign-In SDK
Request Example
// POST /api/v1/auth/google { "id_token": "eyJhbGciOiJSUzI1NiIsImtpZCI6Ijc..." }
Response
200 OK
{ "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "token_type": "Bearer", "expires_in": 86400, // 24 jam dalam detik "user": { "id": "uuid-user-xxx", "name": "Ibu Sari", "email": "sari@gmail.com", "role": "pengelola", "bank_sampah_id": "uuid-bank-xxx", "bank_sampah_nama": "Bank Sampah BTH" }, "is_new_user": false // true jika akun baru dibuat }
401 Unauthorized — ID Token invalid atau expired
500 Internal Server Error — Gagal verifikasi ke Google
POST /auth/refresh Refresh access token
Request Body
FieldTypeRequiredDescription
refresh_tokenstringRequiredRefresh token yang diterima dari /auth/google
Response
200 OK
{ "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "expires_in": 86400 }
401 — Refresh token invalid / expired
POST /auth/logout Logout & invalidate token 🔒 Auth Required

Menghapus / blacklist token di server. Client harus menghapus token dari local storage secara mandiri.

Response
200 OK
{ "message": "Logout berhasil" }

POST /transaksi Catat transaksi setoran baru 🔒 Auth Required
ℹ️ Endpoint ini secara atomik: (1) menyimpan transaksi, (2) menyimpan detail_transaksi dengan snapshot harga, dan (3) mengupdate total_saldo di tabel saldo. Semua dalam satu database transaction.
Request Body
FieldTypeRequiredValidasi
nasabah_idstring (UUID)RequiredNasabah harus aktif (is_active=true) dan milik bank sampah ini
itemsarrayRequiredMin 1 item
items[].jenis_sampah_idstring (UUID)RequiredJenis sampah harus aktif
items[].beratnumberRequiredDesimal max 3 digit, > 0
items[].harga_per_kgnumberOptionalJika tidak diisi, gunakan harga aktif dari master. Pengelola bisa override per item
catatanstringOptionalCatatan tambahan transaksi
Request Example
{ "nasabah_id": "uuid-nasabah-xxx", "items": [ { "jenis_sampah_id": "uuid-jenis-aaa", "berat": 2.5, "harga_per_kg": 3500 // optional override }, { "jenis_sampah_id": "uuid-jenis-bbb", "berat": 1.200 // harga_per_kg tidak diisi → pakai harga master } ], "catatan": "Setoran rutin bulan Juni" }
Response
201 Created
{ "id": "uuid-trx-yyy", "nasabah_id": "uuid-nasabah-xxx", "nasabah_nama": "Ahmad Ridwan", "bank_sampah_id": "uuid-bank-xxx", "dicatat_oleh": "uuid-user-xxx", "tanggal": "2026-06-20T09:30:00Z", // auto-set server "total_nilai": 11500.00, "catatan": "Setoran rutin bulan Juni", "status_wa": "belum_dikirim", "items": [ { "id": "uuid-detail-1", "jenis_sampah_id": "uuid-jenis-aaa", "nama_sampah_snapshot": "Plastik PET", "harga_snapshot": 3500.00, "berat": 2.500, "subtotal": 8750.00 }, { "id": "uuid-detail-2", "jenis_sampah_id": "uuid-jenis-bbb", "nama_sampah_snapshot": "Kertas HVS", "harga_snapshot": 2291.67, "berat": 1.200, "subtotal": 2750.00 } ], "saldo_setelah_transaksi": 461500.00 }

POST /transaksi/:id/notify-wa Kirim / retry notifikasi WhatsApp ke nasabah 🔒 Auth Required

Mengirim notifikasi WhatsApp ke nomor HP nasabah melalui WhatsApp Gateway API. Bisa digunakan untuk pengiriman pertama kali atau retry jika sebelumnya gagal. Mengupdate status_wa di database setelah pengiriman.

Request Body

Tidak perlu request body. Server menggunakan data transaksi yang sudah ada dan template WA dari pengaturan bank sampah.

Pesan WhatsApp yang Dikirim
// Template default (bisa dikustomisasi di /pengaturan/wa-template) Halo {Nama}, setoran sampahmu senilai {Total} sudah kami catat ya. Saldo tabunganmu sekarang adalah Rp {Saldo}. {daftar_item} Terima kasih! 🌿
Response
200 OK — Berhasil dikirim
{ "success": true, "status_wa": "terkirim", "message": "Notifikasi WhatsApp berhasil dikirim" }
400 Bad Request — Gagal kirim
{ "success": false, "status_wa": "gagal", "error": "Nomor tidak aktif di WhatsApp" }
